
# 💰 Personal Transaction Manager

## 📌 About the Project
Personal Transaction Manager is a web-based application developed to help users manage and track their personal financial activities efficiently. It provides a simple platform to record daily income and expenses, monitor account balances, and maintain transaction history.

## ✨ Features
- **User Registration & Login:** Secure user authentication.
- **Dashboard:** Displays total balance, total credit, total debit, and net balance.
- **Add Transactions:** Record income and expense transactions.
- **Transaction History:** View and manage previous transactions.
- **Credit & Debit Management:** Track incoming and outgoing money.
- **User Session Management:** Maintains individual user sessions.
- **Responsive Interface:** Simple and user-friendly design.

## 🛠️ Technologies Used
- Frontend: HTML, CSS, Bootstrap, JavaScript
- Database: MySQL
- API Communication: Axios

## 🎯 Project Objective
The main objective of this project is to provide an easy and organized way to manage personal finances, track daily transactions, and understand spending habits.

## 🚀 Future Enhancements
- Monthly expense reports
- Data visualization using charts
- Budget planning
- Transaction filtering and searching
- Export transaction reports
